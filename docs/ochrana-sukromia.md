# Ochrana súkromia

## Meranie návštevnosti

Na meranie návštevnosti používame vlastnú (self-hosted) inštanciu open-source nástroja
[Umami](https://umami.is/), ktorá beží na našom serveri v Európskej únii. Umami nepoužíva
cookies, nevytvára profily návštevníkov a nezbiera osobné údaje — pracujeme len
s anonymnými súhrnnými štatistikami (počet návštev, zobrazené stránky, krajina, typ
zariadenia, kliknutia na tlačidlo „kopírovať", prepnutie záložky WooCommerce/Webnode). Preto na webe nie je cookie lišta.

## Tretie strany

- **GitHub Pages** — web je hostovaný na GitHub Pages; GitHub pri doručovaní stránok
  spracúva IP adresy podľa [vlastných zásad ochrany súkromia](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **Google Fonts** — písma sa načítavajú z Google Fonts CDN; tvoj prehliadač pri tom
  odošle Googlu svoju IP adresu ([zásady ochrany súkromia Google](https://policies.google.com/privacy)).

Okrem toho web nemá registráciu, nezbiera mená ani e-maily a návštevnícke dáta
neposiela žiadnym ďalším stranám.
