    Ochrana súkromia¶

    Meranie návštevnosti¶

    Na meranie návštevnosti používame vlastnú (self-hosted) inštanciu open-source nástroja Umami, ktorá beží na našom serveri v Európskej únii. Umami nepoužíva cookies, nevytvára profily návštevníkov a nezbiera osobné údaje — pracujeme len s anonymnými súhrnnými štatistikami (počet návštev, zobrazené stránky, krajina, typ zariadenia, kliknutia na tlačidlo „kopírovať", prepnutie záložky WooCommerce/Webnode). Preto na webe nie je cookie lišta.

    Tretie strany¶

    • GitHub Pages — web je hostovaný na GitHub Pages; GitHub pri doručovaní stránok spracúva IP adresy podľa vlastných zásad ochrany súkromia.
    • Google Fonts — písma sa načítavajú z Google Fonts CDN; tvoj prehliadač pri tom odošle Googlu svoju IP adresu (zásady ochrany súkromia Google).

    Okrem toho web nemá registráciu, nezbiera mená ani e-maily a návštevnícke dáta neposiela žiadnym ďalším stranám. Ak je web za heslom, heslo sa overuje len v tvojom prehliadači a na server sa neposiela. Jeho hash si prehliadač zapamätá v lokálnom úložisku, aby sa nepýtal pri každej stránke.
